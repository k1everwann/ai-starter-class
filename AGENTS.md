# AI Starter Class

This is the independent `k1everwann/ai-starter-class` project. Never publish it inside or modify `ai-life-lab` as a substitute.

- Audience: ages 14-18. Traditional Chinese, short sentences. Four tasks with three steps each.
- Keep long setup and teaching notes in the teacher section. Do not turn the student page into a marketing site.
- Plain HTML, CSS and JavaScript; no API keys, backend, analytics, external fonts or dependencies at runtime.
- Keep all nine scenario records fictional. Do not publish real student information, private account data or screenshots of private accounts.
- Label prepared code, fixed exercises, fictional records and screenshots accurately. The in-page workbench is not Codex.
- Preserve source checks, permission awareness, learner-authored changes, actual testing and downloadable results.
- Use safe DOM text handling for learner input. Preview code in an iframe without same-origin privileges and with a restrictive CSP. Editing code invalidates its prior preview.
- State sessionStorage behavior accurately and keep export/clear controls available.
- Keep the root index.html as the site entry. All images belong to this repository; do not depend on the old site.
- Re-run browser tests and regenerate screenshots after visible changes. Do not call Pages live merely because the preparation workflow passed.
